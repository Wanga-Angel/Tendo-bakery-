CSS
i used the color aspect by changing the background of the website page , words and borders to follow my pig pink, brown and yellow color pallet.
I applied the Typography Styles by configuring properties like font-weight and text-transform to ensure the titles look bold and stylized.
For the Layout Structure, I used CSS Flexbox and Grid to position my elements neatly across the page. 
I then added interactive Visual Styles and Pseudo-classes like :hover and :active to make the buttons and tables react with solid, 3D cartoon shadows when clicked. 
I ensured the entire project is Responsive by using relative units (rem and %) instead of fixed pixels. By adding media query breakpoints and image constraints like max-width: 100%, I made sure the navigation bar, logo, and custom flower frames adjust beautifully across mobile, tablet, and desktop screens.
